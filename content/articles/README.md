# 优秀文章:读完之后,要留下结论

这个栏目录的不是「更多链接」,而是**被读完、被拆开、被和站内课程对照过**的文章。
每一篇都只保留三样东西:原文主张什么、证据有多硬、对我们的判断有什么改变。

## 收录标准

- **有一手材料**:优先收录机构/团队发布的原文,二次解读只在补充工程细节时参考。
- **有可迁移的判断**:读完能改变一个决策,而不只是多了一个观点。
- **能和站内课程对上**:要么印证某一讲,要么给出反例或更新。
- **标注代价与局限**:只报喜、不讲失败模式和不适用条件的文章,不进这个栏目。

## 写作模板

每篇归纳统一按这个骨架写,方便横向对照:

1. **一句话结论**:如果只记一句话,记哪句。
2. **两本账**:原文各自的判断、证据与代价。
3. **底层原则**:它们共享的判断,以及彼此的矛盾点。
4. **决策表 / 清单**:能直接拿去用的判断标准。
5. **对我们的启发**:课程、团队、个人三个层面。
6. **打折项**:立场、证据强度、隐性成本。
7. **原文与出处**:一手材料优先,标注日期与作者。
